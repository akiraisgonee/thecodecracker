How we work

Four stages, with the client at every milestone

  1. Weeks 1–3

    Discover

    Requirements sessions, then a signed specification that becomes our contract.

  2. Weeks 4–7

    Build the core

    Sprint 1: login and roles, data, the first working scene. A progress demo at week 7.

  3. Weeks 8–10

    Add the advanced parts

    Sprint 2: all scenes, game modes, real-time features and admin tools.

  4. Weeks 11–12

    Test and deliver

    Sprint 3: testing, fixes, performance and a final demo against every requirement.
